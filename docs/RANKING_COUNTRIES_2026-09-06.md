# Ranking country flags

Implemented country/territory badges beneath player names in Ranking, Hall of Fame
and per-tier Top 10. The name and 24×18 flag are cosmetic and do not affect scoring.
The 249 ISO country/territory images are bundled locally (flag-icons 7.5.0, MIT,
approximately 247 KB total including license). No remote image lookup is made.

At authenticated sign-in, the client calls `POST /profile/country` in auto mode.
Country detection accepts only the configured ingress provider's country header.
The first detected country is inserted atomically with ON CONFLICT DO NOTHING;
subsequent sessions never replace an existing selection, including a hidden flag.
Players can choose another country or hide the badge in Ranking. These choices
are saved to their account, independently of language and score history.

Unknown countries remain unset. Language, display name, timezone and nationality
are never substituted for network country. A flag expresses the player's chosen
representation, not verified nationality or official national-team membership.
Practice-only local progress is still not uploaded to the existing public Ranking.

## Activation on the deployed server (not performed in this local task)

1. Apply `supabase/migrations/048_player_countries.sql` using the existing Supabase
   SQL migration workflow. It adds an isolated table; existing scores are untouched.
2. Deploy the new server/client code. Set server `COUNTRY_GEO_PROVIDER=cloudflare`
   or `COUNTRY_GEO_PROVIDER=vercel` only behind that provider's trusted ingress.
   Ensure the ingress replaces the country header and direct origin access is
   blocked. With the setting absent, automatic network detection is disabled;
   authenticated manual country selection still works after migration.
3. Cloudflare must have IP Geolocation enabled so it sends `CF-IPCountry`.
   Vercel provides `x-vercel-ip-country` on requests reaching its infrastructure.
   Do not forward a user-supplied header unchanged or assume a separately hosted
   API receives headers from the frontend host.
4. Test signed-in accounts from multiple regions, manual override, hidden flag and
   sign-out/sign-in. An old account obtains a flag on its next authenticated visit;
   no historical location backfill is attempted.

Sources: [Cloudflare IP Geolocation](https://developers.cloudflare.com/network/ip-geolocation/)
and [Vercel request headers](https://vercel.com/docs/headers/request-headers).

Country settings report an error if storage is unavailable. Public leaderboard
responses continue to return scores if the optional table is absent/unavailable.
Country enrichment runs after the score-cache lookup, so changing a flag does not
wait five minutes for the existing leaderboard cache to expire. Only country code
is included publicly; no IP address or precise location is stored by this feature.
