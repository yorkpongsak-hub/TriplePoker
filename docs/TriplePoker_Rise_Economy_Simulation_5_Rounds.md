# TriplePoker: Rise — Economy Simulation (5 Rounds per Match)

**วันที่จำลอง:** 28 กรกฎาคม 2026  
**จำนวนรอบ:** 5 รอบต่อแมตช์  
**จำนวนผู้เล่นจำลอง:** 3,000 คนต่อ Scenario  
**ระยะเวลา:** 180 วัน  
**Rake:** 5%  
**Starting Token:** 3,000  
**Daily Income:** 700 Token/วัน (Daily Refill 500 + Login Ad Bonus 200)  

---

## 1. ค่าที่ใช้ในการจำลอง

| Tier | Ante 1/2/3 | Auto Sort | Auction สูงสุด | Call/ครั้ง | Buy-in ทดลอง |
|---|---:|---:|---:|---:|---:|
| C | 10 / 20 / 40 | 0 | 0 | 0 | 500 |
| B | 20 / 50 / 100 | 25 | 0 | 0 | 1,500 |
| A | 80 / 150 / 300 | 99 | 150 | 300 | 8,000 |
| A+ | 250 / 500 / 1,000 | 500 | 500 | 1,000 | 20,000 |

ใช้ Progression Gate ดังนี้:

- B: 15,000 Token และ Day 14
- A: 60,000 Token และ Day 60
- A+: 250,000 Token และ Day 180
- สมมติว่าผู้เล่นผ่าน Skill Gate แล้วเมื่อถึงวันและ Token ที่กำหนด
- Tier ที่ปลดล็อกแล้วไม่ถูกลด Tier เมื่อ Balance ลดลง

## 5. ข้อค้นพบ

### 5.1 เป้าหมาย “ไม่ต่ำกว่า 6 เดือน” ทำงานตามที่ออกแบบ

แม้ผู้เล่น Strong จะมี Token เกิน 250,000 ก่อนกำหนด แต่ยังเปิด A+ ไม่ได้ก่อน Day 180 เพราะ Time Gate เป็นเงื่อนไขบังคับ

### 5.2 ผู้เล่นระดับ Competent ต้องเล่นประมาณ 3 แมตช์/วัน

Competent ที่เล่น 3 แมตช์/วันมีโอกาสถึง A+ ประมาณ 84% และ Median อยู่ที่ประมาณ 294,000 Token จึงเป็นกลุ่มเป้าหมายที่สมเหตุผลสำหรับการปลดล็อก A+ ในเดือนที่ 6

### 5.3 ผู้เล่น Casual ยิ่ง Grind มากอาจยิ่งเสีย Token

Casual มี Advantage เหนือค่าเฉลี่ยเพียงเล็กน้อย แต่ใช้ Auto Sort บ่อยและยังมี Auction/Rake เป็น Token Sink:

- เล่น 1 แมตช์/วัน: Median ยังเหลือประมาณ 95,000
- เล่น 3 แมตช์/วัน: Median ลดเหลือประมาณ 36,000
- เล่น 5 แมตช์/วัน: เริ่มเข้า Queue ไม่ได้หลายครั้ง และ Median เหลือประมาณ 8,000

นี่เป็นความเสี่ยงด้าน Retention เพราะผู้เล่นอาจรู้สึกว่า “ยิ่งเล่นยิ่งจน” โดยไม่เข้าใจสาเหตุ

### 5.4 Daily Income ไม่ทำให้ถึง A+ เอง

รายได้ประจำ 700 × 180 = 126,000 Token รวม Starting Token เป็น 129,000 Token ยังขาดอีกประมาณ 121,000 Token จึงต้องได้กำไรจากการเล่นหรือรางวัล Progression เพิ่มเติม

### 5.5 ผู้เล่น Strong อาจแตะ Arena Threshold เร็วในเชิง Token

Strong ที่เล่น 5 แมตช์/วันมี Median Day-180 ประมาณ 942,000 และ P90 เกิน 1,000,000 Token ดังนั้น Arena Gate ต้องคง Skill Gate และหน้าต่าง Ascendant ไว้ ไม่ควรใช้ Token อย่างเดียว

## 6. ข้อเสนอปรับสมดุล

1. ล็อก Ante/Pot ชุดใหม่ไว้ก่อน ยังไม่จำเป็นต้องลดเพิ่ม
2. ปรับ A+ Buy-in จาก 20,000 เป็น **25,000 ขั้นต่ำ** หรือ **30,000 ที่แนะนำ**
3. คง Day-180 Gate เพราะเป็นตัวรับประกันเวลา 6 เดือนที่แท้จริง
4. เพิ่ม Casual Protection โดยไม่แจก Token ตรง ๆ มากเกินไป เช่น:
   - แสดง Net Token ต่อแมตช์และแยก Auto Sort/Auction/Rake ให้เห็น
   - เตือนเมื่อค่าใช้ตัวช่วยสูงกว่ากำไรเฉลี่ยล่าสุด
   - จำกัดหรือแนะนำงด Auto Sort เมื่อแพ้ต่อเนื่อง
   - มีภารกิจฝึกจัดไพ่ที่ให้รางวัลเล็กน้อย
5. Skill Gate ของ Nine Sentinels ต้องออกแบบให้ผู้เล่น Competent ผ่านได้ใกล้ Day 180 แต่ Casual ยังมีเส้นทางฝึกและกลับมาได้
6. เก็บ Telemetry ช่วง Closed Beta เพื่อแทนค่า Win Probability, Auto Sort Rate, Bid และ Call ด้วยข้อมูลจริง

## 7. ข้อสรุป

Economy ชุดใหม่เหมาะสำหรับเป้าหมาย 6 เดือนในภาพรวม:

- Strong ถูก Time Gate กันไม่ให้ขึ้นเร็วเกินไป
- Competent ที่เล่นสม่ำเสมอประมาณ 3 แมตช์/วันมีโอกาสขึ้น A+ สูง
- Casual ยังต้องมีระบบช่วยเรียนรู้และควบคุม Token Sink เพื่อไม่ให้เลิกเล่น
- จุดที่ต้องแก้ทันทีคือ **A+ Buy-in ไม่ควรต่ำกว่า 25,000 Token** หากระบบตั้งใจให้ Buy-in ครอบคลุม Worst Case ของแมตช์ 5 รอบ

ผลนี้เป็น Monte Carlo สำหรับตรวจทิศทาง ไม่ใช่ค่าทำนาย Final Economy เพราะยังต้องแทนค่าพฤติกรรมจริงจาก Closed Beta โดยเฉพาะอัตราชนะรายกอง, การ Fold, จำนวนผู้ Call, Auction Win Rate, Boss Reward และรางวัลจากภารกิจ
